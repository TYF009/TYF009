# Felix Tong

我做嵌入式设备和网络运维工具，关注软硬件如何协同，以及怎样把设备状态、任务进度和诊断结果呈现得更清楚。

## Selected Projects

- **[AuraBar](https://github.com/TYF009/AuraBar-T113S3)** · 基于 T113-S3 的嵌入式 Linux 触屏。电脑端负责执行任务，设备端显示 Codex 任务状态和结果，也可以播放本地音频和环境声。
- **[FOLI](https://github.com/TYF009/Mini-Printer)** · 一台电池供电的 ESP32 迷你热敏打印机，包含电路、固件、可打印外壳和 Android 应用。应用支持离线编辑、模板和黑白打印预览。
- **[Desktop AI Agent Terminal](https://github.com/TYF009/AI-agent-terminal)** · 用自制 ESP32-S3 电路板做的桌面终端，通过 MCP 让模型读取麦克风的环境音量，并控制实体 RGB 灯的颜色和亮度。
- **[NetGuardian](https://github.com/TYF009/NetGuardian)** · 面向酒店 IT 运维的网络诊断平台，用 FastAPI、Next.js 和 Windows Agent 把 DNS、TCP、TLS、HTTP 检测与故障证据汇总到同一个工作台。

## Field Notes

- **[Canonical Landscape SaaS Case Study](https://github.com/TYF009/canonical-landscape-customer-success)** · 在 Ubuntu 虚拟机上独立验证设备注册和远程管理流程，记录上手过程中的阻碍，并整理支持手册和问题升级流程。
